## 额外发现

- Excel 的 read_only 模式会信任错误的 worksheet dimension，可能把有数据台账读成空快照。现在重置维度，按实际 XML 读取并使用自己的行数限制；低报与高报维度的同名重导入均有 API 回归。
- 工作表 XML 损坏现在返回受控 400，并保持原图。
- 数据库驱动失败响应省略原异常连接串，避免凭据回显。
