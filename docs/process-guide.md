# 流程图使用指南

工作台把业务流程与系统、数据关系放在一起。每张流程是一份独立文档，可以引用数据关系总图中的共享资产；流程中的步骤和排版不会修改资产本身。

## 从审批示例开始

1. 打开工作台，点击顶部 **新建流程**。
2. 填写流程名称，起始画布选择 **申请审批示例**，点击 **创建流程图**。
3. 示例主线为“开始 → 提交申请 → 审核申请 → 是否通过？ → 执行 → 结束”；不通过时进入“修改申请”，再返回审核。
4. 点击一个步骤，在右侧填写负责人、处理规则、输入和产出，点击 **保存修改**。
5. 点击顶部 **图目录**，创建第二张流程或返回 **数据关系总图**。各流程分别保存，不会混在一张画布上。

也可选择“空白流程”，从左侧点击或拖入节点开始。示例只提供通用流程，不预填真实负责人或资产。

## 节点、连线与布局

| 节点 | 用途 | 连接方式 |
| --- | --- | --- |
| 开始 | 流程起点 | 右侧出口，无入口 |
| 处理步骤 | 一项需要完成的工作 | 左侧入口、右侧出口 |
| 条件判断 | 按条件选择后续步骤 | 左侧入口，右侧“是”与底部“否”出口 |
| 结束 | 流程终点 | 左侧入口，无出口 |

从出口圆点拖到另一节点的入口圆点即可创建有向连线。点击连线后，在右侧填写“条件 / 连线说明”，例如“审核通过”或“资料不完整”，再点击“保存修改”。分支文字用于说明，不会实际计算条件或执行审批。可连接不同步骤形成退回环路，不支持节点连接自身。

拖动节点调整位置；空白处左键拖动可框选，右键拖动画布，滚轮缩放，`Shift + 点击` 多选。选中后按 `Delete` 删除节点或连线；删除节点会一并删除与其相连的连线。顶部 **整理布局** 自动排列当前流程，**适应画布** 调整视野。

节点创建、连线、拖动、删除和整理布局完成后直接保存。右侧属性中的文字和资产选择是编辑草稿，需点击 **保存修改** 才写入数据库；顶部保存状态不代表未提交的属性草稿已经保存。

## 关联共享资产

先在数据关系总图中创建、导入或采集系统、数据库、表、接口、文件、外部方等资产，再回到流程：

1. 点击流程步骤，在右侧 **关联资产** 搜索并选择已有资产。
2. 点击 **保存修改**。一个步骤可以关联多个资产，同一资产可供多张流程引用。
3. 点击关联资产旁的 **查看**，跳转到数据图查看该资产。
4. 在数据图选中资产，其属性面板中的 **关联流程** 会列出引用它的流程，点击名称可打开对应流程。

流程只保存资产 ID 引用，引用不复制或修改资产。删除整张流程会保留资产；资产被删除或失效时，已有流程保留旧引用并显示失效状态，方便人工修正。需要新建关联时，该资产必须存在且可用。列表不完整时可点击刷新资产列表。

原有系统视图、业务视图、字段视图仍是同一张数据关系图的不同投影。“业务视图”展示业务环节与系统的关联，独立流程文档用于绘制开始、判断、步骤和结束，两者通过共享资产连接。

## 撤销、重做与多页面修改

每张流程独立保留最多 100 步内容历史，切换到其他流程后再返回可继续使用 `Ctrl + Z` 撤销、`Ctrl + Y` 或 `Ctrl + Shift + Z` 重做。撤销和重做也会保存到数据库，覆盖节点、连线、属性及排版；不会回滚流程名称与说明。

历史保存在当前浏览器会话，刷新页面后清空，已经成功保存的内容不受影响。删除整张流程不属于内容撤销，删除前可导出 JSON 留存。

同一流程在其他页面被修改时，旧页面保存或撤销会报版本冲突，避免覆盖新内容。重新打开该流程获取最新内容后再编辑；重新加载外部新版本时会清理旧的撤销历史。

## 导入、导出与备份

流程工具栏 **导出 → 导出流程 JSON** 保存当前一张流程，包含名称、说明、步骤属性、连线、坐标及关联资产 ID，格式标记为 `process-diagram/v1`。通过 **图目录 → 导入流程文件** 导入时，会创建新文档，不覆盖现有流程；即使导入同一个文件，也会成为另一张流程。

**导出 → 导出图片 PNG** 用于查看或分享，不可恢复为可编辑流程。属性草稿需先保存，再导出所需版本。

两类 JSON 的范围与入口不同：

| 备份 | 包含什么 | 不包含什么 | 恢复入口 |
| --- | --- | --- | --- |
| 原数据图 JSON | 数据图节点、边、来源、人工保护状态及排版 | 所有独立流程文档 | 数据关系总图的“恢复备份” |
| 流程 JSON | 当前一张流程及资产 ID 引用 | 资产实体、其他流程、撤销历史 | 图目录的“导入流程文件” |

流程 JSON 不是整个工作台的备份。跨数据库导入时，引用的资产必须先在目标库存在、ID 一致且可用；缺少或失效引用会使导入失败，不会自动创建同名资产。迁移时可先恢复原数据图 JSON，再逐张导入流程文件。需要保留全部资产与全部流程时，可停服务后复制 `backend/data/dataflow.db`。

## 当前范围

当前版本提供基础流程绘图、资产关联与文档管理，允许保存未完成草稿。单张流程最多 500 个节点、2000 条连线，界面导入的流程 JSON 最大 10 MiB。

暂不包含执行引擎、实际任务派发、泳道或子流程。图中的负责人、规则、输入与产出用于梳理和沟通，保存流程不会自动调用系统或发起审批。
