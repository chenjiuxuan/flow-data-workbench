## 验证

- 浏览器：使用独立临时 SQLite 库验证拖动、撤销、重做、刷新后的持久化、属性保存，以及 Delete 后撤销恢复节点和所有关联边；PostgreSQL CTE 预览与并入正确，错误 SQL apply 前后图 revision 相同。未写入用户现有数据库。

## 边界

- MySQL/PostgreSQL 采集的连接参数、实例隔离和反射失败行为有模拟回归，本轮没有连接真实业务数据库。
- 没有表结构元数据时，星号只提供表级依赖并提示字段未知；歧义字段报错，MERGE 仍仅提供表级血缘。
- 旧版物理资产不自动删除或改名；旧版多来源状态采用保守保留，等待各来源完整采集确认。
